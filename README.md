# Pickup Description Panel

Мод для **Risk of Rain 2**: отдельная панель с названием и полным описанием предмета, на который наведён прицел. Показывает предметы и экипировку на земле, известные товары в торговых терминалах и мульти-магазинах, включая лунные терминалы в Базаре. Текст берётся из выбранного языка игры, в том числе русского.

**Версия: 1.0.0.** Инструкция рассчитана на Windows и Steam. Всё необходимое для установки описано ниже: достаточно ссылки на этот репозиторий. Готовый архив находится в папке `release`; собирать код или устанавливать инструменты для программирования не нужно.

## 1. Скачайте мод из репозитория

1. На главной странице этого репозитория на GitHub нажмите зелёную кнопку **Code**, затем **Download ZIP**.
2. В «Загрузках» нажмите на скачанный архив правой кнопкой мыши и выберите **Извлечь всё**.
3. Откройте распакованную папку проекта. В её названии может быть окончание `-main` или имя другой ветки.
4. Внутри откройте папку **release**. Там лежит **PickupDescriptionPanel-1.0.0.zip** — это архив для установки в менеджер модов. Оставьте его запакованным.

На этом этапе у вас два разных архива: скачанный с GitHub архив всего проекта и ZIP мода внутри него. В **Import Local Mod** нужно будет выбрать именно `PickupDescriptionPanel-1.0.0.zip` из папки `release`.

Порядок скачивания репозитория приведён также в [инструкции GitHub](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives).

## 2. Установите менеджер r2modman

Если r2modman уже установлен и настроен для Risk of Rain 2, переходите к шагу 3.

1. Закройте игру.
2. Откройте [страницу r2modman на Thunderstore](https://thunderstore.io/c/riskofrain2/p/ebkr/r2modman/).
3. Нажмите **Download** или **Manual Download** на странице пакета.
4. Распакуйте скачанный ZIP через **Извлечь всё**.
5. Запустите `r2modman Setup … .exe` и пройдите установку. Подойдёт предложенная установщиком папка.
6. Откройте r2modman, выберите **Risk of Rain 2** и **Steam**, если программа спросит платформу.
7. Нажмите **Create new**, назовите профиль, например `ItemDescriptions`, и откройте его через **Select profile**.

Профиль — это отдельный набор модов и настроек. Можно использовать уже существующий профиль для игры с друзьями.

## 3. Установите BepInExPack

BepInExPack — загрузчик, который позволяет игре запускать моды.

1. В выбранном профиле откройте раздел **Online**.
2. Найдите `BepInExPack` от автора **bbepis**.
3. Нажмите **Download**, затем **Download with dependencies**, если появится такой выбор.
4. Дождитесь установки. Дополнительные пакеты, которые менеджер установит вместе с загрузчиком, оставьте включёнными.

В архиве мода указана зависимость `bbepis-BepInExPack-5.4.2121`. Подходит и более новая совместимая сборка BepInEx 5 для RoR2. Если [BepInExPack](https://thunderstore.io/c/riskofrain2/p/bbepis/BepInExPack/) уже установлен и включён, повторная установка не нужна. Самому Pickup Description Panel дополнительные R2API и HookGenPatcher не требуются.

## 4. Импортируйте мод

1. Проверьте, что в r2modman выбран нужный профиль.
2. Откройте меню профиля **внизу слева** и нажмите **Import Local Mod**. В старых версиях пункт может находиться в **Settings** и называться **Install local mod**.
3. В окне выбора файла откройте распакованную папку репозитория, затем **release**.
4. Выберите **PickupDescriptionPanel-1.0.0.zip** и подтвердите импорт. Если менеджер предложит установить зависимости, согласитесь.
5. Откройте **Installed**. В списке должен появиться **PickupDescriptionPanel**, автор пакета — **Shem**. Проверьте, что он и BepInExPack включены.

Если раньше вы копировали DLL этого мода вручную, при закрытой игре удалите ту ручную копию перед импортом, чтобы не оставлять дубликат плагина.

Меню профиля перенесено вниз слева начиная с [r2modman 3.2.0](https://github.com/ebkr/r2modmanPlus/blob/develop/CHANGELOG.md#320). Способ импорта описан в [Installing mods locally](https://github.com/ebkr/r2modmanPlus/wiki/Installing-mods-locally).

## 5. Запустите игру и проверьте панель

1. Откройте Steam и нажмите **Start modded** в r2modman.
2. Дождитесь главного меню и начните забег.
3. Подойдите к выпавшему предмету или известному товару в магазине.
4. Наведите прицел так, чтобы появилась обычная подсказка подбора или покупки. Справа должна появиться панель описания.
5. **F8** выключает и включает панель. Выбор сохраняется в настройках.

Для следующих запусков с модом используйте **Start modded** в том же профиле. Это стандартный способ запуска в [инструкции R2Wiki](https://risk-of-thunder.github.io/R2Wiki/Playing/Getting-Started/).

Панель использует цель взаимодействия игры, поэтому нужно находиться достаточно близко к предмету. Скрытый товар с вопросительным знаком не раскрывается; закрытые сундуки, уже купленные товары и меню выбора предметов не показываются. При смене цели панель обновляется или исчезает. Меню, которое перехватывает управление, скрывает панель.

## Настройки

После первого запуска игры с модом в папке профиля появляется файл:

```text
BepInEx\config\com.alex.pickupdescriptionpanel.cfg
```

Закройте игру. В r2modman откройте **Config editor**, найдите `com.alex.pickupdescriptionpanel`, выберите **Edit Config**, измените значения и сохраните. Если конфига ещё нет, запустите игру через Start modded до главного меню, закройте её и снова откройте редактор. Файл можно также открыть Блокнотом через папку профиля — оба способа описаны в [R2Wiki](https://risk-of-thunder.github.io/R2Wiki/Playing/Getting-Started/#configuring-mods).

| Параметр | По умолчанию | Что меняет |
| --- | --- | --- |
| `Enabled` | `true` | Показывать панель. `false` выключает её. F8 меняет эту настройку. |
| `ToggleKey` | `F8` | Клавиша переключения; можно указать, например, `F9`. |
| `X` | `0.72` | Положение по горизонтали: от `0` слева до `1` справа. |
| `Y` | `0.32` | Положение по вертикали: от `0` сверху до `1` снизу. |
| `Width` | `400` | Ширина панели при 1080p, от `240` до `800`. |
| `Scale` | `1` | Дополнительный масштаб, от `0.5` до `2`. |
| `FontSize` | `19` | Размер текста описания, от `12` до `36`. |

Дробные значения записывайте **через точку**: `0.72`, а не `0,72`. Панель ограничивается краями экрана, её масштаб также учитывает высоту экрана.

Чтобы увеличить панель и текст, попробуйте `Scale = 1.2`. Чтобы сдвинуть панель влево, уменьшите `X`. Для длинного описания можно увеличить `Width` или уменьшить `FontSize`. Высота ограничена 65% экрана; для переполнения предусмотрена прокрутка, но доступность курсора во время игры зависит от режима управления.

Значения по умолчанию:

```ini
[General]
Enabled = true
ToggleKey = F8

[Panel]
X = 0.72
Y = 0.32
Width = 400
Scale = 1
FontSize = 19
```

## Где находится папка профиля

В **Settings** найдите действие **Browse profile folder**. В некоторых версиях оно находится во вкладке **All** или **Locations**. Для установки через Import Local Mod эта вкладка не нужна.

При стандартной установке r2modman на Windows можно нажать **Win + R**, вставить путь ниже и нажать Enter. Затем откройте папку с названием своего профиля:

```text
%APPDATA%\r2modmanPlus-local\RiskOfRain2\profiles
```

Если вы переносили данные менеджера на другой диск, используйте Browse profile folder: стандартный путь может отличаться.

## Решение проблем

### Панель не появляется

1. Проверьте запуск через **Start modded** и профиль, в который импортирован мод.
2. В **Installed** проверьте, что включены PickupDescriptionPanel и BepInExPack.
3. Подойдите к обычному выпавшему предмету до появления подсказки взаимодействия. Закройте паузу и другие меню.
4. Нажмите F8 один раз. Если это не помогло, при закрытой игре установите `Enabled = true` в конфиге и перезапустите её.
5. Проверьте журнал по инструкции ниже.

Для проверки используйте обычный выпавший предмет или показанный товар. Сундук, товар с `?` и уже купленный товар не подходят.

### Import Local Mod выдаёт ошибку

Проверьте, что выбран `release/PickupDescriptionPanel-1.0.0.zip`, а не ZIP всего репозитория, скачанный через Code. В корне нужного архива должны быть четыре файла:

```text
PickupDescriptionPanel.dll
manifest.json
icon.png
README.md
```

Если в скачанном репозитории вообще нет папки `release`, проверьте выбранную ветку на GitHub и скачайте основную ветку заново. Для исходников без готового архива понадобится сборка по разделу в конце README.

Если импорт всё равно не проходит, сохраните текст ошибки и используйте ручную установку ниже.

### Текст дублируется или панель мешает

Отключите старый **Pickup Item Descriptions**, если он добавляет описание в подсказку подбора. Положение и размер нашей панели меняются в конфиге; F8 временно скрывает её.

### После обновления игры мод перестал работать

Отключите PickupDescriptionPanel в Installed и проверьте запуск без него. Обновления игры могут менять API, поэтому старой DLL иногда нужна новая сборка. Передайте автору журнал и версию игры.

### Как получить журнал

В папке профиля откройте `BepInEx\LogOutput.log`. При успешной инициализации плагина в нём есть строка:

```text
Pickup Description Panel loaded. Toggle: F8
```

Если клавиша изменена, в строке будет другая клавиша. Сообщение подтверждает загрузку плагина; работу панели нужно проверить в забеге.

Для обращения за помощью приложите журнал последнего запуска, версию игры, список других модов и описание того, какой предмет проверяли и что произошло. Если журнала нет, проверьте запуск через Start modded и установку BepInExPack.

## Ручная установка в профиль

Это запасной способ, если импорт недоступен. Сначала установите BepInExPack по шагу 3.

1. Закройте игру и распакуйте `release/PickupDescriptionPanel-1.0.0.zip`.
2. Откройте папку нужного профиля.
3. Внутри `BepInEx\plugins` создайте папку `PickupDescriptionPanel`.
4. Скопируйте в неё `PickupDescriptionPanel.dll` из архива.
5. Запустите игру через **Start modded**.

Итоговый путь внутри профиля:

```text
BepInEx\plugins\PickupDescriptionPanel\PickupDescriptionPanel.dll
```

При ручном копировании запись мода в Installed может отсутствовать. Используйте один способ установки: импорт ZIP или ручное копирование DLL.

## Обновление и удаление

Для обновления скачайте свежий репозиторий с GitHub и импортируйте ZIP из его папки `release` в тот же профиль при закрытой игре. Если менеджер не предлагает заменить установленный пакет, удалите PickupDescriptionPanel из Installed и повторите импорт. Перед обновлением можно сохранить копию своего CFG.

Чтобы временно отключить мод, выключите его в **Installed** и перезапустите игру. Для удаления выберите **Uninstall** у PickupDescriptionPanel. При ручной установке удалите только ранее скопированную DLL из `BepInEx\plugins\PickupDescriptionPanel`.

## Игра с друзьями и совместимость

Поделитесь ссылкой на этот репозиторий: каждый сможет скачать мод и установить его по инструкции выше. У каждого игрока, которому нужна панель, должна быть своя установка.

Код работает на клиенте и не меняет покупки или предметы в сетевой сессии. В режиме с несколькими локальными игроками используется первый игрок. Описание берётся из данных игры; индивидуальный эффект с учётом всего инвентаря не рассчитывается.

Версия 1.0.0 собрана на DLL локально установленной игры. Проверены компиляция и структура архива для импорта. Работа в запущенной игре, кооператив и совместимость с другими модами пока не проверены.

## Сборка из исходников

Этот раздел предназначен для разработки. Для обычной установки используйте готовый ZIP из `release`.

Нужны исходники репозитория, установленная Risk of Rain 2, Windows и .NET Framework 4.7.2+ для компилятора. Скрипт использует DLL вашей игры; библиотеки игры не входят в распространяемый архив. .NET SDK не требуется.

Откройте PowerShell в папке проекта и выполните:

```powershell
New-Item -ItemType Directory -Force .deps
Invoke-WebRequest 'https://thunderstore.io/package/download/bbepis/BepInExPack/5.4.2121/' -OutFile .deps/BepInExPack.zip
Expand-Archive .deps/BepInExPack.zip .deps/BepInExPack -Force
Invoke-WebRequest 'https://www.nuget.org/api/v2/package/Microsoft.Net.Compilers.Toolset/4.14.0' -OutFile .deps/Roslyn.zip
Expand-Archive .deps/Roslyn.zip .deps/Roslyn -Force
./build.ps1 -GameDirectory 'C:\Program Files (x86)\Steam\steamapps\common\Risk of Rain 2'
```

В последней команде укажите свою папку игры. При необходимости передайте `-BepInExCore` с путём к `BepInEx\core` нужного профиля.

DLL и ZIP появляются в `dist`. Копия готового ZIP также записывается в `release`, чтобы её можно было включить в репозиторий и получить через Code → Download ZIP. Папки `dist` и `.deps` исключены из Git, а `release` нужно включать в коммит вместе с обновлёнными исходниками и README. Скрипт не устанавливает мод в профиль и не публикует ничего на GitHub.

После изменения кода проверьте в игре предметы и экипировку на земле, смену товаров, покупку, товар с вопросительным знаком, смену языка, F8, паузу и переход между уровнями. Убедитесь, что панель помещается на экран и не оставляет повторяющихся исключений в журнале.

При разработке использованы [R2Wiki — First Mod](https://risk-of-thunder.github.io/R2Wiki/Mod-Creation/Getting-Started/First-Mod/) и [пример Pickup Item Descriptions](https://github.com/haddad-github/Pickup-Item-Descriptions-RoR2-Mod). Пример изучен для получения цели взаимодействия; отдельная панель реализована без изменения ContextManager.
